# Ad-Free YouTube Chrome Extension

A Chromium-based browser extension that overrides YouTube's scripts and opens the selected video using an alternative ad-free player (yout-ube.com).

## Features
* Redirects to a 3rd-party website.
* Some settings.

## File structure
* `manifest.json` - extension config file.
* `script.js` - main script.
* `main.html` / `popup.js` - UI/UX.

## Installation
1. Download the files.
2. Open the extensions management page in your browser.
3. Activate **Developer mode**.
4. Click **Load unpacked** and choose the correct folder.
5. Refresh YouTube (grant storage permissions if prompted).
